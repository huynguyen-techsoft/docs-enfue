<Update label="Mar 29, 2026" description="Improvements">

  - Fixed the header.
  - Fixed a bug when importing a CV from a link.
</Update>

<Update label="Mar 22, 2026" description="New changes">

  - New filter bar.
  - The Jobs and Internship tables now work the same way.
  - You can add photos in the editor.
  - Improved the applicant table and upload screens.
</Update>

<Update label="Mar 15, 2026" description="UI improvements">
  - Improved the applicant upload screen.
  - Improved the data import screen.
  - Minor fixes.
</Update>

<Update label="Mar 8, 2026" description="Features and fixes">

  - Fixed job messages.
</Update>

<Update label="Mar 1, 2026" description="New features">

</Update>
