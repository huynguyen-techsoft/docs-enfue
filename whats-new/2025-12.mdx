<Update label="Dec 28, 2025" description="New features">
  - Evaluation requests by email.
  - Free trials are now 14 days.
  - A notification appears after an import finishes.
  - Company admins can turn on and set up their [career page](/workplace/career-page).
  - Fixes to the integrations page and career page.
</Update>

<Update label="Dec 21, 2025" description="Features and fixes">
  - You can now send attachments with emails.
  - Import a ZIP file to create applicants.
  - Improved CSV import and fixed applicant UI issues.
</Update>

<Update label="Dec 14, 2025" description="UI changes">
  - New time-range filter for company admins.
  - Upload a CV to create an applicant.
  - Fixed job list UI issues.
</Update>

<Update label="Dec 7, 2025" description="Features and fixes">
  - Adding applicants now uses tabs.
  - Improved the job view.
  - Fixed dashboard, job list, and appointment UI issues.
</Update>
