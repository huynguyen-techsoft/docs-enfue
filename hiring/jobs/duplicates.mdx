The same person sometimes applies more than once, for example through your career page and again through a job board. The **Duplicates** tab collects these repeated applicants in one place so you can spot them before they clutter your pipeline.

## View duplicates

1. Open the job from **Hiring → Jobs**.
2. Click the **Duplicates** tab.

The heading shows how many duplicates were found, for example **7 duplicates**. Applicants with the same email address or phone number appear one under another, so you can compare them.

| Column | What it shows |
| --- | --- |
| **Name** | The applicant's name. |
| **Email** | The email address on the application. |
| **Phone** | The phone number on the application. |
| **Stage** | Where each copy of the applicant is in your pipeline. |
| **Title** | The applicant's current job title, if known. |
| **Social** | Links to the applicant's social profiles, if provided. |
| **Portfolio** | A link to the applicant's portfolio, if provided. |

<Tip>
Check the **Stage** column before you clean anything up. If one copy has already moved forward, for example to **Matching**, keep that one so you don't lose its progress.
</Tip>

<Info>
Duplicated applicants can also be disqualified with the reason **Duplicated Applicant**, which then shows up in the job's [disqualified reason breakdown](/hiring/jobs/job-report).
</Info>
